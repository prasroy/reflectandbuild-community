# QuietKite community

Feedback and ideas for apps by [QuietKite](https://quietkite.pages.dev), starting with **FocusLock**.

| I want to… | Go to |
|---|---|
| Suggest a FocusLock improvement or nice-to-have feature | [New idea](https://github.com/prasroy/quietkite-community/issues/new?template=focuslock-idea.yml) |
| Share how FocusLock works for me | [New feedback](https://github.com/prasroy/quietkite-community/issues/new?template=focuslock-feedback.yml) |
| Propose a new app QuietKite should build | [New app idea](https://github.com/prasroy/quietkite-community/issues/new?template=new-app-idea.yml) |
| Vote for an idea | Add a 👍 reaction to it ([ideas sorted by votes](https://github.com/prasroy/quietkite-community/issues?q=is%3Aissue+label%3Aidea+sort%3Areactions-%2B1-desc)) |
| Get private help, or anything else | [Contact](https://quietkite.pages.dev/contact/) |

Everything here is public, and shows on the website: the [ideas board](https://quietkite.pages.dev/apps/focuslock/ideas/) and the [feedback wall](https://quietkite.pages.dev/apps/focuslock/feedback/). Feedback appears on the website only if you tick the consent box.

## How ideas move

`status:under-review` → `status:planned` → `status:in-progress` → `status:shipped` (closed as completed). Ideas that won't be built are closed as "not planned", with a short reason.

## House rules

Be kind and specific. Don't post personal data, credentials, or anything from your employer. Off-topic, abusive, or spam posts are removed.

## For the maintainer: moderation

- Set the status by swapping the `status:*` label. The website updates live.
- Hide a post from the website without deleting it: add the `hidden` label.
- Merge duplicates: close as duplicate, and link the original so votes move there.
